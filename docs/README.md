# Baking Journal Documentation

This directory contains a complete documentation project for the app, authored in the format consumed by **The Baking Journal** Odoo module.

- `baking-journal/the-bakers-archive-mobile-companion/` is the importable project tree.
- Every file carries the YAML frontmatter expected by the Journal importer.
- `00-project-index.md` is the project homepage.
- `<n>-<category>/00-category-index.md` is a category landing page.
- Remaining files are documentation pages.

If you are updating the app, update these pages in the same commit so the public reference never lags the implementation.
