# The Baker's Archive Mobile Companion

*A Flutter companion app for The Baker's Archive*

The Baker's Archive Mobile Companion is a cross-platform Flutter app for browsing the recipes published by an Odoo-based Baker's Archive website. It is a read-only client of the archive's public REST API with a local offline layer for saved recipes.

This is the full reference for version `1.0.0`. It is written so it can be imported directly into The Baking Journal Odoo module as a single documentation project.

If you are new to the app, start with **Getting Started**. If you are integrating, extending or debugging it, **App Architecture**, **Data & REST API** and **Build & Release** stand on their own.
