Version 1.0.0

Migrated the companion to the new Flutter mobile design.

Added the archive-aware Explore feed with search, responsive recipe cards and adaptive Android launcher icons.
Added the full recipe view with baker's math batch scaling, ingredient checklists and per-step timers.
Added offline favourites with local recipe caching.
Added Kitchen Mode with large-text, step-by-step guidance and countdown.
Added server configuration, connection testing, optional Odoo sign-in, offline cache management and Warm Crust / Dark Toast themes.
The release is Android-only.
Builds and release notes are managed through Toasty Deployer on Linux; releases are created on GitHub, Toasty Software's GitLab and Google Play.
